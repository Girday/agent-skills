# Нормоконтроль и пределы автоматизации

Проверки самой поставки и непроверенные режимы: [validation.md](validation.md). Они не заменяют проверку нового документа.

## Этапы

1. **Данные:** тип/профиль/редакция, локальные требования, применимость каждого пункта карты; реальные реквизиты, результаты, источники; отсутствие незаполненных полей.
2. **Сборка:** успешный код выхода, устойчивые `.aux/.toc/.out`, нет undefined references/citations, missing character, дублированных меток. Рассмотреть каждый overfull/underfull: не подавлять предупреждения вместо исправления.
3. **Объективные измерения:** MediaBox каждой страницы; параметры/фактические границы текста; основной шрифт/кегль/цвет/базовые линии; абзацы; номера страниц. TeX pt и PDF bp различны. Метрики записываются только в начале документа и не обнаруживают последующую локальную перенастройку.
4. **Визуальный просмотр всех страниц:** заголовки/новые страницы/пустоты, кириллица/математика, колонтитулы, таблицы/подписи/продолжения, приложения. Число осмотренных страниц должно совпасть с числом страниц PDF; для больших отчётов вести диапазоны просмотра. Проверять при читаемом масштабе, при необходимости увеличивать проблемные места.
5. **Содержательные связи:** все названия/страницы toc; каждое первое упоминание и положение объекта; подписи, номера, расшифровки, переходы; статистика реферата; порядок источников/приложений.
6. **Организационные условия:** настоящие подписи/даты/печать, регистрация, утверждение, нормоконтроль, бумага/печать/подача — только по отдельным подтверждениям, не выводить из файла.

## Рендер

Использовать установленный `pdftoppm`/`mutool`/иной доступный рендерер. Пример:

```bash
pdftoppm -r 110 -png /absolute/report/build/main.pdf /absolute/report/build/page
```

Если Poppler не находит fontconfig, укажи **временный** конфиг с системными папками шрифтов и доступным каталогом кеша через `FONTCONFIG_FILE`; не меняй пользовательскую конфигурацию ради просмотра. Не оставляй зависший процесс повторять сообщения. Проверка извлечённого текста не заменяет рендер.

## Что проверяет audit.py

| Проверка | Основание | Ограничение |
|---|---|---|
| Сборка/ссылки/глифы | Финальный log | Не доказывает научную правильность |
| Переполнения | Overfull/underfull | Нужна визуальная оценка; наличие float может вызвать косметическое предупреждение |
| Объявленные поля/абзац/шрифт | `.gostmetrics` | Начальная конфигурация; локальные изменения возможны |
| Незаполненные данные | Шаблонные маркеры в `.tex` | Не распознаёт все возможные заглушки; комментарии пропускаются |
| Реальные форматы | MediaBox через pdfplumber | A3 допустим только при применимости; поворот учитывается |
| Границы текста | Координаты символов PDF | Не все графика/линии; допуск 0,8 мм; анализ подвала отделён; результат REVIEW требует осмотра |
| Пагинация | Физические страницы 2..N и центр подвала | Продолжение титула, вставки со своим счётом, несколько книг/начальный N требуют ручного анализа |

`audit.py` требует только стандартную библиотеку; дополнительные геометрические проверки выполняются при наличии `pdfplumber`. Для среды без него укажет `NOT_CHECKED`. Код 0 значит «нет обнаруженных ошибок в выполненных проверках»; `certified` всегда false. Код 1 — обнаруженная ошибка, 2 — нет сборки. Для демонстрационного шаблона ожидается ошибка незаполненных данных до замены полей.

## Записка о соответствии

Составь `compliance-report.md` отдельно от отчёта:

```markdown
Профиль: НИР / учебная адаптация
Редакция: ГОСТ 7.32-2017, поправки ИУС 2–2019, 3–2020, 1–2022
Источник и дата проверки: …
Локальные требования: …
Выбор реализации: 14 bp, гарнитура …, нумерация …

| Пункт | Применимость | Статус | Доказательство / что осталось |
|---|---|---|---|
| 6.1.1 поля | да | PASS | параметры + измерения страниц … |
| 5.2.2 | один исполнитель | PASS | сведения на титуле, отдельного списка нет |
| 6.6.3 | многостраничная таблица | REVIEW | продолжение на с. … ещё не просмотрено |
| 3.5 | да | NOT_CHECKED | подтверждения нормоконтроля нет |

Отклонения и основания: …
Незаполненное: …
Визуально просмотрено: страницы … из …
Итог: что готово и что препятствует сдаче.
```

Для полного нормоконтроля пройти все применимые строки requirements.md, а не только четыре строки образца. `NOT_APPLICABLE` требует основания (например, нет патентных исследований или таблиц). Не переносить машинный PASS на весь пункт с несколькими независимыми требованиями. Служебный отчёт не выдавать за официальный акт организации.
