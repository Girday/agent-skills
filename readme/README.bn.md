## Codex-এ ইনস্টল করা

Codex-কে বলুন:

```text
$skill-installer ব্যবহার করে https://github.com/Girday/agent-skills/tree/main/skills/gost-7-32-2017-latex ইনস্টল করো।
```

অথবা রিপোজিটরি ক্লোন করে স্থানীয় কপি ইনস্টল করুন:

```bash
git clone https://github.com/Girday/agent-skills.git
cd agent-skills
python3 scripts/install.py gost-7-32-2017-latex
```

ইনস্টলার `$CODEX_HOME/skills` ব্যবহার করে। `CODEX_HOME` নির্ধারিত না থাকলে `~/.codex/skills` ব্যবহার করে। এটি বিদ্যমান ইনস্টলেশন প্রতিস্থাপন করে না। ইনস্টল করা কপি রিপোজিটরি থেকে স্বাধীন; রিপোজিটরির পরিবর্তনে স্বয়ংক্রিয়ভাবে আপডেট হয় না। দক্ষতা দেখা না গেলে Codex পুনরায় চালু করুন। দক্ষতা খোঁজা ও বিতরণের উপায় [সরকারি নির্দেশিকায়](https://learn.chatgpt.com/docs/build-skills) আছে। এই রিপোজিটরি সোর্স ফাইল দেয়; এটি প্রকাশিত প্লাগইন ডিরেক্টরি এন্ট্রি নয়।

`SKILL.md` সমর্থন করে এমন অন্য এজেন্টও এসব উপকরণ ব্যবহার করতে পারে। Codex-এর ডেস্কটপ সরঞ্জাম ঐচ্ছিক; কমান্ড লাইনের বিকল্পও দেওয়া আছে।

## এজেন্টের জন্য প্রসঙ্গ তৈরি

একই ইনস্টলারে নাম বা GitHub ফোল্ডার দিয়ে `build-agent-context` ইনস্টল করুন। তারপর বলুন:

```text
$build-agent-context ব্যবহার করো। এই আর্কাইভ থেকে প্রসঙ্গ তৈরি করো, যাতে অন্য
এজেন্ট প্রকল্পের কাজ চালাতে পারে। বর্তমান চাহিদা, উৎস, অমীমাংসিত বিরোধ ও
শুরুর প্রম্পট রাখো। প্রসঙ্গ গ্রহণকারী এজেন্ট ফাইল পড়তে পারে।
```

দক্ষতাটি একটি স্বয়ংসম্পূর্ণ নথি অথবা সংক্ষিপ্ত প্রবেশবিন্দুর সঙ্গে বিষয়ভিত্তিক ফাইল বেছে নেয়। আসলে কী পড়া হয়েছে তা নথিবদ্ধ করে, মূল অংশের সূত্র সংরক্ষণ করে এবং চাহিদা, যাচাইকৃত তথ্য, অনুমান ও অগ্রগতি আলাদা রাখে। বিদ্যমান প্রসঙ্গও হালনাগাদ করা যায়। বাধ্যতামূলক রানটাইম নির্ভরতা নেই; আর্কাইভ, স্ক্যান ও অন্য ফরম্যাটের জন্য উপযুক্ত সরঞ্জাম দরকার।

## GOST দক্ষতার ব্যবহার

```text
$gost-7-32-2017-latex ব্যবহার করো। সংযুক্ত উপকরণ থেকে প্রতিবেদন তৈরি করো,
PDF বানাও এবং বিন্যাস যাচাই করো। প্রতিষ্ঠানের চাহিদা আলাদাভাবে সংযুক্ত আছে।
```

রিপোজিটরির মূল ফোল্ডার থেকে চালান:

```bash
python3 skills/gost-7-32-2017-latex/scripts/init_project.py ./my-report
python3 skills/gost-7-32-2017-latex/scripts/build.py ./my-report
python3 skills/gost-7-32-2017-latex/scripts/audit.py ./my-report
```

`init_project.py` চালানোর পর `my-report/metadata.tex` পূরণ করুন এবং বিল্ডের আগে নমুনা লেখা বদলান। প্রাথমিক টেমপ্লেটে ইচ্ছাকৃতভাবে খালি ঘর রাখা আছে; সেগুলো পূরণ না করা পর্যন্ত অডিট ব্যর্থ হওয়ার কথা। PDF-এর জ্যামিতিক মাপ যাচাইয়ের জন্য `pdfplumber` ইনস্টল করুন; এটি না থাকলে সংশ্লিষ্ট পরীক্ষা `NOT_CHECKED` হিসেবে চিহ্নিত হয়।

আট পৃষ্ঠার উদাহরণ, চাহিদার মানচিত্র এবং যাচাইকৃত আচরণ ও সীমাবদ্ধতা:

- [example.pdf](../examples/gost-7-32-2017/example.pdf)
- [requirements.md](../skills/gost-7-32-2017-latex/references/requirements.md)
- [validation.md](../skills/gost-7-32-2017-latex/references/validation.md)

GOST 7.32-2017 গবেষণা প্রতিবেদনের জন্য প্রযোজ্য। শিক্ষামূলক কাজে ব্যবহার করতে হলে প্রতিষ্ঠানের নিয়ম অনুযায়ী মানিয়ে নিতে হবে। দক্ষতাটি বাধ্যতামূলক চাহিদা, সুপারিশ, অনুমোদিত বিকল্প ও টেমপ্লেটের সিদ্ধান্ত আলাদা করে। স্বয়ংক্রিয় পরীক্ষা পর্যালোচনায় সহায়তা করে; প্রতিবেদনকে প্রত্যয়িত করে না এবং স্বাক্ষর, নিবন্ধন বা প্রাতিষ্ঠানিক অনুমোদন নিশ্চিত করে না। A3 ও একাধিক খণ্ডের পদ্ধতি নথিভুক্ত, তবে প্রাথমিক যাচাইয়ে আলাদাভাবে পরীক্ষা করা হয়নি।

## উন্নয়ন

ভার্চুয়াল এনভায়রনমেন্ট তৈরি করে আপনার shell-এর কমান্ড দিয়ে সক্রিয় করুন; এরপর নির্ভরতা ইনস্টল ও পরীক্ষা চালান:

```bash
python3 -m venv .venv
python -m pip install -r requirements-dev.txt
python scripts/validate.py
python -m unittest discover -s tests -v
ruff check .
ruff format --check .
```

XeLaTeX থাকলে LaTeX ইন্টিগ্রেশন পরীক্ষা চলে; না থাকলে তা বাদ যায়। GitHub Actions সোর্স ও Python পরীক্ষা যাচাই করে; তৈরি প্রতিবেদন রেন্ডার বা প্রত্যয়িত করে না।
