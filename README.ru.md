# Agent Skills

Полезные навыки для AI-агентов: инструкции, скрипты, шаблоны и проверки для повторного использования в разных проектах.

[English](README.md) · [Как добавить навык](CONTRIBUTING.md) · [Лицензия MIT](LICENSE)

## Каталог

| Навык | Назначение | Требования |
|---|---|---|
| [gost-7-32-2017-latex](skills/gost-7-32-2017-latex/) | Подготовка и проверка отчётов в LaTeX по ГОСТ 7.32-2017: титул, структура, формулы, таблицы, источники, приложения, аудит PDF | Python 3.10+, XeLaTeX или LuaLaTeX; `pdfplumber` для измерений PDF |

В коллекции пока один навык. Каждый хранится в отдельной папке с `SKILL.md`, инструкциями, исполняемыми помощниками и необходимыми ресурсами.

## Установка

В Codex можно попросить:

```text
Используй $skill-installer и установи https://github.com/Girday/agent-skills/tree/main/skills/gost-7-32-2017-latex
```

Или установить из локальной копии:

```bash
git clone https://github.com/Girday/agent-skills.git
cd agent-skills
python3 scripts/install.py gost-7-32-2017-latex
```

Установщик использует `$CODEX_HOME/skills`, по умолчанию `~/.codex/skills`, и не перезаписывает существующий навык. Установленная копия не обновляется автоматически при изменении репозитория. Если навык не появился, перезапустите Codex. Механизм навыков и варианты распространения описаны в [официальной документации](https://learn.chatgpt.com/docs/build-skills). Здесь опубликованы исходники навыков; коллекция не является записью в каталоге плагинов.

Пример запроса после установки:

```text
Используй $gost-7-32-2017-latex. Подготовь отчёт по приложенным материалам,
собери PDF и проверь оформление. Учти требования кафедры из отдельного файла.
```

## Что есть в навыке ГОСТ

- [Карта всех разделов и приложений стандарта](skills/gost-7-32-2017-latex/references/requirements.md), включая исключения и неоднозначности.
- LaTeX-шаблон и команды создания, сборки и аудита проекта.
- [Демонстрационный PDF](examples/gost-7-32-2017/example.pdf) с условными данными.
- [Описание выполненных проверок](skills/gost-7-32-2017-latex/references/validation.md) и границ автоматизации.

ГОСТ посвящён отчётам о НИР. Для лабораторных, курсовых и других учебных работ требуется адаптация к правилам учебного заведения. Начальный шаблон содержит незаполненные реквизиты: до их замены проверка должна выявлять ошибку. Размер 14 пт выбран шаблоном; норма задаёт минимум 12 пт, а Times New Roman рекомендует.

Для запуска команд из репозитория:

```bash
python3 skills/gost-7-32-2017-latex/scripts/init_project.py ./my-report
# Заполните metadata.tex и замените демонстрационный текст.
python3 skills/gost-7-32-2017-latex/scripts/build.py ./my-report
python3 skills/gost-7-32-2017-latex/scripts/audit.py ./my-report
```

Автоматический аудит помогает нормоконтролю, но не подтверждает научную достоверность, подписи, регистрацию или утверждение организацией. Для геометрических проверок нужен `pdfplumber`; без него соответствующие проверки получают `NOT_CHECKED`. A3 и многокнижный режим описаны, но отдельно не испытаны в начальной проверке шаблона.

Команды проверки репозитория — в [Development](README.md#development). Оригинальные инструкции, код и шаблоны опубликованы под MIT; тексты стандартов и сторонние шрифты не входят в поставку и не перелицензируются.
